## 블록별 상세 브리핑 (발표 대본용 가이드)

### 1. 문제 (Problem)
- **헬스장 통신 음영**: 지하실에 위치한 피트니스 센터가 많아 네트워크 렉으로 인해 세트 간 기록이 끊김.
- **도구의 분편화**: 루틴 타이머 앱, 운동 일지 앱, 식단 칼로리 계산 앱이 제각각이라 운동 중 앱 전환이 매우 불편함.
- **불필요한 과금 유도**: 단순 세트 카운트 기능조차 월간 구독을 요구하는 상용 앱에 대한 불만.

### 2. 고객군 (Customer Segments)
- **주 타깃**: 체계적인 3분할/4분할 루틴을 배우고 무게/횟수를 누적 관리하고 싶은 헬스 초·중급자.
- **부 타깃**: 탄수화물/단백질/지방 매크로 섭취량과 수분 섭취를 직관적으로 체크하고 싶은 다이어터 및 유지어터.

### 3. 고유 가치 제안 (Unique Value Proposition)
- **"All-in-One Offline Fitness Dashboard"**
- 브라우저만 켜면 로그인이나 API 연결 없이 0.1초 만에 즉시 실행되며, 운동 루틴 + 실시간 세트/휴식 타이머 + 식단 매크로 + 누적 통계가 유기적으로 하나로 연결됩니다.

### 4. 솔루션 (Solution)
1. **스마트 분할 루틴 추천 & 커스텀 빌더**: PPL 3분할, 4분할, 상하체 2분할, 홈트 등 50+ 종목 라이브러리 탑재.
2. **실시간 세트 로거 & 사운드 휴식 타이머**: 세트 완료 체크 시 Web Audio 알림 및 60~120초 최적 휴식 카운트다운.
3. **일일 매크로 식단 & 수분 트래커**: 한국인이 즐겨 먹는 35+ 헬스 식단 프리셋과 8잔 수분 트래커.
4. **신체 변화 & 누적 볼륨 통계**: 부위별 훈련 밸런스 및 체중 변화 추이 시각화.

### 5. 채널 (Channels)
- GitHub Repository 및 GitHub Pages 배포 (누구나 원클릭 포크 및 실행 가능)
- AI Studio & Vercel 정적 웹 Publish 링크

### 6. 핵심 지표 (Key Metrics)
- 주간 운동 완료 횟수 (주 3~5회 목표 달성도)
- 총 리프팅 볼륨 (누적 kg/톤 계산을 통한 점진적 과부하 추적)
- 일일 권장 칼로리 및 단백질(g) 목표 달성률

### 7. 비용 구조 및 경쟁 우위 (Cost & Advantage)
- 클라이언트 저장소(`localStorage`)를 활용하므로 **서버 운영비 0원**.
- 외부 API 의존성이 없어 서비스 중단 위험이 전혀 없으며 전 세계 어디서든 오프라인 구동 가능.
