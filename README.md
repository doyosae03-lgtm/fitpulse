# FitPulse - 스마트 운동 루틴 & 식단 기록 웹 애플리케이션 🏋️‍♂️

> **100% 오프라인 독립 구동 지원** · 외부 API 종속성 없는 완전한 클라이언트 피트니스 & 식단 관리 솔루션

---

## 📌 프로젝트 소개
**FitPulse**는 지하 헬스장처럼 네트워크가 불안정한 환경에서도 끊김 없이 운동 루틴을 확인하고, 세트별 중량과 반복 횟수를 체크하며, 식단 탄·단·지 매크로 영양소를 기록할 수 있는 올인원 피트니스 대시보드입니다.

- **배포 플랫폼**: GitHub Pages (Zero Config 자동 빌드 & 배포)
- **핵심 기술**: React 19, TypeScript, Tailwind CSS, Lucide Icons, Web Audio API, LocalStorage

---

## ✨ 주요 기능

### 1. 운동 루틴 플래너 & 맞춤 생성기
- **부위별 분할 추천**: 3분할 PPL(밀기/당기기/하체), 4분할, 상하체 2분할, 홈트 맨몸, 체지방 연소 유산소 탑재
- **커스텀 루틴 빌더**: 40여 종목 운동 라이브러리에서 직접 종목과 세트, 중량, 횟수를 조합하여 나만의 루틴 저장

### 2. 실시간 운동 세트 로거 & 사운드 휴식 타이머
- **실시간 지표 추적**: 경과 시간, 세트 진행률, 세션 총 볼륨(kg) 자동 계산
- **사운드 피드백**: 세트 체크 시 Web Audio 알림음 발생
- **세트 간 휴식 타이머**: 45초, 60초, 90초, 120초 등 목표에 맞춘 자동 카운트다운 타이머

### 3. 일일 식단 & 3대 영양소(탄·단·지) 매크로 트래커
- **칼로리 프로그레스 게이지**: 목표 칼로리 대비 실시간 섭취량 및 잔여량 표시
- **탄·단·지 영양 바**: 3대 영양소 분할 진행률 시각화
- **한국형 헬스 식단 내장 DB**: 닭가슴살, 현미밥, 계란, 소고기 우둔살 등 35+ 대표 식단 원클릭 추가
- **8잔 수분 트래커**: 일일 권장 수분 섭취량 인터랙티브 체크

### 4. 통계 & 신체 분석 대시보드
- 누적 운동 세션 횟수 및 누적 톤(Ton) 단위 볼륨 추적
- 부위별(가슴, 등, 하체, 어깨, 팔, 복근, 유산소) 훈련 밸런스 차트
- 날짜별 체중 변화 기록 및 목표치 관리
